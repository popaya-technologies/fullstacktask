Full-Stack Developer Assignment
Notes Management System
Overview
This assignment is designed to evaluate your ability to build a complete full-stack
application, including frontend, backend, API design, and database integration.
You are required to develop a Notes Management System that allows users to create,
manage, and search through multiple notes efficiently.
